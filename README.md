# 康威生命游戏 · Conway Life

用原生 HTML、CSS 和 JavaScript 实现的方块规则模拟器，提供康威生命游戏、电线世界和布赖恩大脑三种二维同步演化模式。

**在线试玩**（当前正式版 v1.6.1）：<https://huajitongxue.github.io/conway-life/> —— 直接用浏览器打开即可游玩，无需下载或安装。

当前版本：**v2.0.0-beta3**（预发布，多模式版本，尚未验收）。**最新正式版仍是 v1.6.1**。每次启动先选择模式，各模式共用场地、历史回放、回放文件、预设和主题功能。

已发布的桌面版可在 [GitHub Releases](https://github.com/huajitongxue/conway-life/releases) 下载。Electron `.exe` 为免安装程序；Tauri `setup.exe` 和 `.msi` 是两种安装程序，选择一种即可。

## 快速开始

下载仓库 ZIP 并解压，或克隆仓库：

```bash
git clone https://github.com/huajitongxue/conway-life.git
```

双击目录中的 `index.html` 即可运行；它会打开 `web/index.html`。也可以直接打开 `web/index.html`。请保持 `web/` 内的 HTML、CSS 和 JavaScript 相对位置不变。

网页无需安装依赖、构建或启动服务器，不加载外部库、字体及 CDN，支持离线使用。建议使用支持 Canvas、Pointer Events 和 ResizeObserver 的现代浏览器。

### Windows 桌面版

桌面版使用 Electron，启动后默认最大化，直接显示游戏，没有浏览器的标签页、地址栏和收藏夹栏。按 `F11` 切换全屏，按 `Esc` 退出全屏；其余操作与网页版一致。

打包产物为 `dist/Conway-Life-1.6.1-Windows-x64.exe`，适用于 Windows 10 / 11 的 x64 系统。双击即可运行，无需安装 Node.js、浏览器或其他依赖。免安装程序启动时会解压到临时目录，首次打开可能稍慢。

自定义预设保存在 `%APPDATA%\conway-life`，移动或替换 `.exe` 不会清除预设。网页版和桌面版的存储相互独立，已有浏览器预设不会自动迁移。

### Tauri Windows 版

项目同时提供 Tauri 2 的 Windows x64 版本，有三种形态：

- **免安装单文件** `Conway-Life-X.Y.Z-Tauri-Windows-x64-portable.exe`：就是 Tauri 编译出来的裸 `conway-life.exe`，只有约 9 MB，自带全部依赖，双击即可运行，不用安装。它比 Electron 版小十倍以上，代价是依赖系统 WebView2（见下）。**想要最小、启动最快就用这个。**
- **NSIS 安装版** `...-Tauri-Windows-x64-setup.exe`
- **MSI 安装版** `...-Tauri-Windows-x64.msi`

后两种是同一个程序的两种安装格式，任选一种安装即可，不需要都装；安装界面为简体中文，NSIS 默认仅为当前用户安装。

Tauri 各版本都使用系统 WebView2。Windows 11 自带，通常不用管；Windows 10 需要机器上装过 Microsoft Edge（绝大多数机器都有）。确实缺少 WebView2 时，安装程序会联网下载并安装运行时，不内置离线 WebView2 安装包；**免安装单文件不会自动装运行时，缺 WebView2 时会启动失败**，此时请用安装版或先手动装 WebView2 Runtime。装好之后游戏本身可以离线运行。

v1.6.1 的产物已作为 [v1.6.1 Release](https://github.com/huajitongxue/conway-life/releases/tag/v1.6.1) 的附件发布，本地产物位于 `dist/`：

- `Conway-Life-1.6.1-Windows-x64.exe`（Electron 免安装版）
- `Conway-Life-1.6.1-Tauri-Windows-x64-portable.exe`（Tauri 免安装单文件）
- `Conway-Life-1.6.1-Tauri-Windows-x64-setup.exe`（Tauri NSIS 安装版）
- `Conway-Life-1.6.1-Tauri-Windows-x64.msi`（Tauri MSI 安装版）

开始 Tauri 开发前，需要安装 Rust stable-msvc、Microsoft C++ Build Tools 和 WebView2。运行开发版：

```bash
npm ci
npm run tauri:dev
```

检查 Rust 项目：

```bash
npm run tauri:check
```

生成两种 Tauri Windows x64 安装包：

```bash
npm run tauri:build
```

原始安装包生成于 `src-tauri/target/release/bundle/nsis/` 和 `src-tauri/target/release/bundle/msi/`，交付时复制到 `dist/` 并按上述文件名区分 Electron 与 Tauri。首次构建可能需要联网下载 Rust 依赖、NSIS 和 WiX 工具。

**如果只是本地自己玩，用这条就够了**（不生成安装包，构建更快）：

```bash
npm run tauri:portable
```

它执行 `tauri build --no-bundle`，然后把裸 exe 复制成 `dist/Conway-Life-<版本>-Tauri-Windows-x64-portable.exe`，结束时打印完整路径，双击即可运行。正式发布不需要本地构建，交给 GitHub Actions（见下文「发布约定」）。

NSIS 和 WiX 缓存放在项目的 `src-tauri/target/.tauri/` 内，避免在 C 盘重复保存打包工具。

Tauri、Electron 和浏览器共用 `web/` 目录中的游戏页面。不同运行方式的自定义预设分别保存在各自的 WebView 存储中，不会自动互相迁移。

### 桌面版开发与打包

在本项目目录中安装依赖，需要 Node.js 22.12 或更新版本：

```bash
npm ci
npm start
```

生成 Windows x64 免安装程序：

```bash
npm run dist
```

仅生成解压后的程序目录（`dist/win-unpacked/`）：

```bash
npm run pack
```

首次安装与打包需要联网下载 Electron 和打包工具；生成的桌面程序可以完全离线运行。构建产物和 `node_modules/` 不提交到代码仓库，依赖版本由 `package-lock.json` 固定。打包命令不会自动发布到 GitHub。

如果下载 Electron 时连接 GitHub 超时，可在当前 PowerShell 窗口临时设置镜像后再打包；文件校验保持开启：

```powershell
$env:ELECTRON_MIRROR = 'https://npmmirror.com/mirrors/electron/'
$env:ELECTRON_CUSTOM_DIR = '{{ version }}'
$env:ELECTRON_BUILDER_BINARIES_MIRROR = 'https://npmmirror.com/mirrors/electron-builder-binaries/'
npm run dist
```

这些设置只影响当前终端及其子进程，不会修改系统环境变量；开发时首次运行 `npm start` 下载超时也可使用同一组设置。

### 发布约定

后续打包好的桌面程序统一作为 GitHub Release 附件发布：Electron 免安装版、Tauri 免安装单文件和 Tauri 两种安装版会放在同一个 Release 中。代码仓库保留源码和构建配置，不提交 `dist/`、`node_modules/` 或本地测试文件。**v1.6.1 的源码已提交并推送，四个可执行文件和校验文件（共五个附件）已随 `v1.6.1` 标签正式发布**（版本号里没有 `-` 后缀，所以不是预发布，MSI 也在其中）。

每次发布保持 `VERSION`、npm 元数据、Rust 元数据、Tauri 配置和 README 的版本号一致，写好 `docs/releases/vX.Y.Z.md`，提交并推送源码，最后推送对应的 `vX.Y.Z` 标签。**推送标签后由 GitHub Actions 自动完成打包和发布**（配置见 `.github/workflows/build.yml`）：它会先核对各文件版本号、标签和发布说明是否齐全，再在 GitHub 的 Windows 环境上打包 Electron 免安装版和 Tauri 的免安装单文件 / NSIS / MSI，算出校验值并创建或更新 Release，上传四个可执行文件和校验文件（共五个附件）。整个过程不需要本地构建，也不需要开着电脑。

日常本地构建只需要 `npm run tauri:portable`（出免安装单文件自用）；`npm run dist`（Electron）和 `npm run tauri:build`（Tauri 安装包）留给 GitHub Actions 使用，需要本地验证时也可以跑。也可以手动触发上面那个工作流做一次「只构建、不发 Release」的演练。

## 功能

- 启动先进入模式选择页，三张 7×7 预览卡片同时以 10 fps 演算；支持方向键切换焦点、`1`/`2`/`3` 选择、`Enter` 进入。每次启动都重新选择模式。
- Conway 保持 B3/S23 和细胞年龄突变；新增四状态 Wireworld 电线世界与三状态 Brian’s Brain 布赖恩大脑。
- 共用 UInt32 状态场地、同步演化、环绕／有限边界、历史记录、主题和预设。模式切换会丢弃场地；历史记录开启时先确认并清空。
- Wireworld 默认 4 步/秒，提供导线、电子头、电子尾笔刷；导线可拖画，电子头和尾只支持点击，右键点击或拖拽擦除。系统预设含直线、拐角、三通和时钟环。
- Brian’s Brain 默认 15 步/秒，提供“亮”和“暗色（将熄）”笔刷，均可点击或拖画，右键擦除；场地以 8% 随机亮格开局，系统预设提供双格点火图案。
- 自定义预设按所属模式过滤并保存各格状态；旧预设缺少模式时按 Conway 读取。
- 固定 **120 列 × 80 行**逻辑网格，画布保持 3:2 比例并随窗口大小调整。
- 标准 **B3/S23** 规则，采用包含对角线的 8 邻域。
- 默认环绕边界，可切换有限边界；切换模式会保留现有细胞。
- 播放、暂停、前进一步、倒退一步、倒放、清空和随机填充；显示代数、当前模式的非空格数量和历史位置。
- 速度范围 **1～60 步/秒**，默认 10 步/秒；支持滑块及 `+1`、`+10`、`-1`、`-10` 微调。
- 网格线开关；主场地单元格边长达到 6 像素时显示网格线。
- Conway 系统预设：滑翔机、脉冲星、高斯帕滑翔机枪；Wireworld 和 Brian’s Brain 提供各自的预设。
- 默认 **80×50** 自定义形状编辑器，编辑大形状时按图案尺寸扩展，支持绘制、擦除、整体拖动和保存时自动裁剪空白；已有形状可以重新打开继续修改。
- 主场地和形状编辑器支持滚轮循环切换当前模式笔刷；“框选”支持从场地提取图案，松开即保存为新形状。
- 形状管理弹窗集中处理已有形状：新建空白形状、修改已有形状、把任意形状“复制一份”成新的自定义预设。
- 系统预设与自定义预设合并显示在右侧预设库，卡片提供缩略图；左上角“＋”菜单提供复制、改名、删除、左右翻转和顺时针旋转 90° 等操作。
- 预设只能拖拽到场地，放置时会追加到现有细胞；系统预设不可删除，自定义预设支持删除。
- 自定义预设支持改名，也可以勾选后导出成 JSON 文件备份，或从文件导入；导入的图案会追加到预设库。
- 细胞突变可单独配置：每秒抽取数量、单个细胞突变概率、死亡／移动比例，以及优先选择稳定细胞；参数保存在本地，启用状态每次打开游戏时默认关闭。
- 深色主题；桌面端完整地图与控制面板同屏，预设列表独立滚动，窄屏采用上下布局。
- 左 Ctrl 显示左下角为原点的格子坐标，左 Shift 切换实时放大镜（150%～300%）；左 Shift 快捷键可以在设置中关闭。
- 统一设置管理快捷键／画布提示、坐标开关及细胞突变；显示偏好和放大倍率保存在本地。
- 设置提供多种预设主题色及一个可覆盖的自定义颜色；细胞、预设缩略图、编辑器和界面高亮一起换色，保留深色背景。
- 历史记录默认关闭，可在“历史回放”区域按需开启；记录可导出为二进制回放文件，再导入回看。倒放模式保持只读，明确退出后才能编辑。

## 操作

| 操作 | 功能 |
| --- | --- |
| 鼠标左键点击或拖拽主场地 | 使用当前模式笔刷绘制状态 |
| 鼠标右键点击或拖拽主场地 | 擦除细胞，阻止右键菜单 |
| 主场地／编辑器内滚动鼠标滚轮 | 向上切换前一种笔刷，向下切换后一种，首尾循环 |
| 点击“框选”后左键拖拽主场地 | 松开即保存选中区域的方块为新形状 |
| `Space` | 播放／暂停；倒放模式中暂停或继续倒放 |
| `←` | 暂停并倒退一条历史记录 |
| `→` 或 `N` | 暂停并前进一条记录；位于最新位置时执行新一代 |
| `R` | 暂停并按当前模式随机填充 |
| `C` | 清空场地 |
| `Esc` | 取消框选或关闭当前弹窗 |
| 左 `Ctrl`（按住） | 显示主场地鼠标所在格子的坐标 |
| 左 `Shift`（按一下） | 开启／关闭放大镜 |

启动模式选择页时，`←`／`→` 移动卡片焦点，`1`、`2`、`3` 选择对应模式，`Enter` 进入当前焦点模式。游戏顶部“切换模式”返回选择页；历史记录开启时会先确认清空。

普通模式绘制时会暂停演化和突变，正常松开鼠标后恢复原来的正向播放；原来暂停的保持暂停。取消手势、失去指针捕获或窗口失焦时，保留已绘制内容并保持暂停。普通模式允许播放期间拖放预设。手动绘制、预设放置和突变不会推进代数；最新位置的前进一步或自动演化才会推进代数。清空和随机填充会将代数重置为 0，开启历史记录时可通过倒退撤回。倒放只读模式中不允许修改场地。

### 历史回放

点击“历史回放：关／开”标题按钮切换历史记录，每次打开游戏默认关闭，不保存开关状态。鼠标悬停可查看开关说明。关闭时不会创建历史快照，倒退、倒放和导出不可用；播放、前进一步、绘制、突变及其他正常操作仍可使用。点击开启后，从当前场地、代数和细胞年龄保存起点，此前没有记录的变化不能补回。

关闭已经开启的记录时会暂停并弹出确认。确认后清空全部历史（含当前位置之后的记录），释放快照引用，保留当前场地；下一次开启将重新记录。取消、点击遮罩或按 Esc 不清空历史，并恢复此前的播放方向和状态。若在倒放只读模式中确认关闭，会同时解除只读并保持暂停；正常正向播放中确认关闭则继续演化。需要保留历史时，请先取消并导出回放。

控制区提供“倒退一步”“倒放”和“前进一步”。倒放沿用速度滑块，每一步恢复一条历史，到最早保留的位置自动暂停；再次点击倒放或按空格也能暂停。倒放是独立只读模式：暂停、抵达起点及前后单步均不会解锁，“前进一步”到末端不会生成新一代。按“退出倒放”解除只读并保持暂停，再播放时从历史位置正向重播到最新位置，然后继续正常演化。

倒放只读期间，点击／拖拽场地、预设放置、清空、随机、边界切换和突变参数修改都被禁止；可以使用坐标、放大镜、速度、网格线、显示偏好、预设库管理及回放导出。退出倒放后才能导入回放。

开启记录后，每代演化、实际发生的突变、一笔绘制或擦除、一次预设放置、清空、随机、边界切换和突变参数修改都会进入历史。一次操作没有改变状态时不记记录。“历史位置”显示的是保留记录中的位置，与游戏代数不同；同一代可以包含多次突变或手工操作。按钮下方显示可倒退／前进次数、当前模式以及记录的操作类型。

记录开启期间保存起点和最近 **2,000 次变化**，最多 2,001 个快照。容量满后淘汰最早记录并给出状态提示；关闭记录并确认、刷新页面或关闭程序后清除。Conway 历史包含细胞连续存活代数，其他模式保存各自的格子状态；数组数据最多约 **77 MB**（另有少量元数据及临时副本），不保存截图。回放直接恢复记录，不重新生成随机填充或随机突变；关闭记录后仍维护 Conway 细胞年龄，供优先稳定细胞的突变规则使用。

退出倒放后，在过去的位置改变场地、切换边界或修改突变设置，会从该处产生新分支，丢弃之后的旧记录；没有实际变化的操作保留旧记录。回看会恢复当时的边界、突变开关和参数，但不会改写永久保存的突变参数；主动修改并保存突变设置才会写入本地存储。播放速度、网格线、显示偏好和预设库不随历史回退，形状编辑器的修改也不属于场地历史。

### 回放文件

“导出回放”保存所有仍保留的记录，包括当前位置之后的记录、细胞连续存活代数、边界、突变参数、代数及操作类型。文件扩展名为 `.conway-replay`，是可以重新导入的游戏状态文件，不是视频，也不包含预设库和显示偏好。

网页版／Electron 通过下载保存；Tauri 弹出原生另存为并提示实际路径。导出会临时暂停，成功、取消或失败后恢复此前播放模式。满容量文件约 77 MB，读写时还需要临时副本，内存峰值会高于常驻历史占用。

“导入回放”在记录关闭时也可使用：先验证整个文件，随后确认是否替换当前场地和历史。确认成功后自动开启历史记录，暂停在最早保留的记录，可向前回看或播放；预设库和永久设置保持不变。取消、坏文件、超限或读取失败不会替换原历史或改变记录开关，并恢复此前播放状态。文件操作期间禁止场地修改或切换记录，不能同时进行另一项回放文件操作。

格式版本为 2：8 字节标识 `CWLREPL\0`，随后是小端 Uint32 版本及元数据长度、包含模式的 UTF-8 JSON 元数据，以及按记录顺序排列的小端 UInt32 状态值。Conway 状态表示细胞年龄，其他模式表示规则状态。v1 文件没有模式字段，导入时按 Conway 处理；跨模式回放会拒绝导入。大小上限 80 MiB，元数据上限 1 MiB；网格尺寸必须匹配当前场地，最多 2,001 条记录。状态范围或其他字段无效时整份拒绝导入。

历史快照包含模式和该模式的状态数组；只有 Conway 快照保存突变参数。历史开关仍默认关闭，开启后从当前模式和场地开始记录。模式切换确认成功后返回选择页，进入新模式时使用演示场景且记录关闭。

### 坐标、放大镜与显示设置

按住左 Ctrl，在画布左下角显示当前格子坐标。左下角为 `(0,0)`，右上角为 `(119,79)`；只改变显示坐标，不改变内部演化。松开按键、鼠标移出、窗口失焦或打开弹窗会隐藏。右 Ctrl 不触发，设置中可以关闭这项提示。

左 Shift 按一下切换放大镜。面板浮在右上角，不改变主场地大小；移入主场地时实时放大鼠标附近区域，并用黑白十字准星标出鼠标的实际位置。靠近场地边缘时，准星随真实裁剪位置移动，不固定在预览中央；移出场地、窗口失焦或打开弹窗后清空预览和准星，面板仍保留。下方滑块和“＋25%／−25%”按钮调节 150%～300% 倍率，默认 200%，相对主场地显示尺寸计算。边缘预览只裁剪真实地图区域，不显示另一侧的环绕内容。放大镜面板会显示左 Shift 状态；在设置中关闭快捷键后，面板仍可手动关闭。

右侧“设置”内可分别关闭快捷键小贴士、画布操作提示、Ctrl 坐标提示和左 Shift 放大镜快捷键，并配置细胞突变。显示偏好及倍率保存在本地，放大镜启动时默认关闭。关闭左 Shift 快捷键并保存时，已打开的放大镜会一并关闭。设置采用保存／取消草稿；保存外观选项不改变历史或永久突变参数。倒放时突变区域仅能查看，但显示选项仍可保存。游戏快捷键在所有弹窗和文本输入区域中暂停生效。

建议先使用振荡图案，前进数代后逐步倒退／重播；再启用突变确认随机过程能原样回看，并尝试在过去绘制、清空和放置预设，检查新分支行为。长时间运行时留意记录满容量后的响应速度和内存使用。

### 主题颜色

打开“设置 → 主题颜色”，点击预设色块选择薄荷、荧光绿、青蓝、海蓝、薰衣草、紫罗兰、玫粉、珊瑚、琥珀或月白。默认沿用原来的薄荷色，背景保持深色；保存后细胞、拖放预览、预设缩略图、编辑器及界面高亮同步换色，放大镜也会跟随场地显示。

点击“自定义”展开 RGB 色卡，用色相条选择色域，鼠标悬停查看该位置的 RGB 数值，左键点击选取。R、G、B 输入框可以直接点击修改，范围为 0～255 的整数。预览色块和色卡标记会同步更新；悬停本身不会替换颜色。

只保留一个自定义颜色，下一次选色或输入 RGB 会覆盖此前的自定义色。切换到预设色仍会记住这个自定义色，之后点击“自定义”可以再次选用。所有颜色操作先进入设置草稿，点击“保存设置”后应用并保存在本地；取消、关闭或按 Esc 会丢弃本次修改。空值或不合法的 RGB 数字会提示修正，不能保存。

换色不改变细胞、代数、突变设置或回放历史，倒放只读模式下也可以修改颜色。颜色属于各平台本地显示偏好，不包含在形状或回放导出文件中。自定义细胞颜色精确使用所选 RGB；若选得过暗，界面高亮会自动提亮以保持文字可读，细胞本身不提亮。

### 预设库

当前模式的系统预设和自定义预设都在右侧“预设库”中。按住卡片并拖到场地，松开后放置；预设**只支持拖拽**，单独点击不会改变场地。预设文件 v2 保存所属模式与格子状态；旧文件和缺少模式的预设按 Conway 导入。

拖放时显示半透明预览，并在已有细胞上追加图案，不清空场地。松开位置作为图案中心；环绕模式下越界部分从另一侧出现，有限模式下越界部分裁掉。

预设卡片左上角的“＋”会打开浮动操作菜单，菜单不会触发拖拽。系统预设提供“复制一份”、左右翻转和顺时针旋转 90°；自定义预设提供改名、删除、左右翻转和顺时针旋转 90°。中间显示缩略图，底部单独显示名称。长名称会省略，悬停可查看完整名称。列表只纵向滚动。变换始终作用于当前显示方向，并同步更新缩略图、拖拽预览和最终放置方向，仅在当前页面会话内有效，刷新后恢复原始方向。

预设库标题下方有“导出形状”和“导入形状”两个按钮，用来备份或迁移预设。

**导出形状**是勾选式的：点一下进入选择模式，每张卡片左上角出现一个勾选框，点卡片本身就等于勾选或取消，勾中的卡片会整块变成灰色。这时上方换成“全选 / 导出所选 / 取消”三个按钮，“导出所选”上会显示已勾选的数量。勾好后点“导出所选”，选中的形状写成一个 JSON 文件，文件名形如 `conway-life-presets-20261010.json`；一个都没勾时会提示先勾选。选择模式期间拖拽放置暂停，按 `Esc` 或点“取消”可以退出且不导出。系统预设也能一起勾选，导出后再导入会变成自定义预设。

导出位置因运行方式而异：

- **网页版**：浏览器自己处理下载，在浏览器的下载栏里能看到。
- **Tauri 桌面版**：弹出 Windows 原生的“另存为”对话框，可以自己选目录；保存后左下角提示里会带上完整路径。
- **Electron 桌面版**：弹出保存对话框。

**导入形状**：选择一个之前导出的 JSON 文件，文件里的图案会**追加**到现有预设库，不会覆盖或清空已有预设。导入的编号取当前最小的可用编号，名称沿用文件里的名字，只有文件里没有名字时才回退成“预设1”“预设2”。

- 文件里无法识别的条目会被跳过，导入完成后提示实际导入和跳过的数量；文件不是有效 JSON、没有任何预设或超过 500 个预设时会给出提示，过程中不会改动已有预设。
- 导出文件只包含图案本身（所属模式、名称、宽高和格子状态），不包含场地、代数、速度和突变设置；卡片上临时做的左右翻转或旋转也不会写进文件。

### 框选场地图案

点击“形状管理”左侧的“框选”，游戏会立即暂停演化和突变。在主场地按住左键拖出矩形，松开即可保存为当前模式的新自定义形状；单击可提取单个格子。选框会按格子对齐，支持任意方向拖动，拖出场地时终点限制在边缘，即使使用环绕边界也不会跨到另一侧选择。

保存时使用当前最小可用编号命名为“预设N”，自动裁掉外围空白并保留内部间隔。Conway 只保存细胞位置，其他模式保留每个方块的状态。支持框选整张场地；从倒放画面也能提取形状，原场地、代数、历史位置及未来记录不变。

保存成功后自动退出框选；空区域会提示重新选择。存储失败时不会加入临时预设，仍可重新拖选重试。按右键、`Esc` 或再次点击“取消框选”可退出；窗口失焦、切后台或指针被取消时放弃未完成的选框。保存或取消后都保持暂停，需要手动播放。

框选期间不能播放、前后导航历史或修改场地，坐标和放大镜仍可用；打开形状管理、编辑器、设置等其他操作前会先取消框选。

### 自定义预设

1. 点击右侧预设库标题旁的“形状管理”。
2. 点击“＋ 新建空白形状”。
3. 在编辑器中点击格子切换状态，或拖拽连续绘制；右键可擦除。
4. 点击“保存为新预设”，图案会裁剪空白，并出现在预设库中。
5. 拖拽卡片到场地，追加图案；点击卡片不会改变场地。
6. 点击卡片上的“改名”重命名。名称最多 16 个字符，不能为空，也不能和另一个自定义预设重名；按 `Enter` 或点“保存名称”生效，按 `Esc` 取消。名称会立即写入本地存储。
7. 点击卡片上的“删除”移除该预设，并更新本地存储。

预设命名为“预设1”“预设2”等，每次保存会使用当前最小的可用编号，例如删除“预设1”后再次保存会重新使用“预设1”。自定义预设保存在当前浏览器的 `localStorage` 中，刷新或再次打开页面可恢复；不会上传到服务器。清除浏览器存储、更换浏览器或移动网页路径可能导致无法访问原来的预设，建议先用预设库的“导出形状”备份，换到别处后再“导入形状”恢复。游戏场地和播放状态不会自动保存。

### 形状管理

点击预设库标题旁的“形状管理”打开弹窗，里面按预设库顺序列出全部形状（系统预设在前，自定义预设在后），最前面还有一个“＋ 新建空白形状”。

- **修改已有形状**：点形状卡片就能进入编辑器改它。编辑器会载入原来的图案（放在编辑区左上角），保存按钮变成“保存修改”，保存后**覆盖这个形状**，编号和名称都保持不变。系统预设是程序内置的，不能直接修改，点了会提示先“复制一份”。
- **编辑与整体拖动**：修改已有形状时，左键单击空白格新增细胞，单击当前笔刷对应的方块删除，右键点击或拖拽擦除。从空白区域按住左键拖动可以移动整个图案；轻微的鼠标抖动仍按单击处理，整体拖动不会额外点亮起始格。编辑区默认 80×50，遇到更大的形状时按各方向所需尺寸扩展，图案移动不会超出当前编辑区。重新新建空白形状时恢复默认尺寸，仍使用空白区域拖拽绘制。
- **复制一份**：每张卡片右下角有“复制一份”，把该形状复制成一个新的自定义预设，名称自动取“原名 副本”“原名 副本2”等避免重名。系统预设也能这样复制成可自由修改的自定义预设。
- 弹窗里点空白处、点 `×` 或按 `Esc` 都能关闭；弹窗打开期间游戏快捷键不会改变场地或播放状态。

### 细胞突变

细胞突变只在 Conway 模式的“设置”中显示。默认关闭，参数默认为每秒抽取 10 个细胞、单个细胞 10% 概率、死亡和移动各占 50%。打开设置时游戏会暂停，保存或取消后恢复打开前的播放状态。启用后，正常演化播放期间每秒从当前存活细胞中抽取指定数量，并让每个被抽取的细胞按概率发生突变：按死亡／移动比例死亡，或向上、下、左、右随机移动一格。移动目标已有细胞或有限边界越界时，该次移动保持原位；环绕边界会从另一侧出现。突变不会增加代数，但会立即更新画面和存活数量。历史重播不重新生成突变，倒放只读时不能修改参数。

勾选“优先选择长时间未改变的细胞”后，会优先抽取连续存活代数最多的格子；代数相同时随机选择，不重复抽取。未触发突变时不补抽。默认不勾选，勾选状态会随参数保存在本地，旧设置自动按未勾选处理。

新生、手动绘制和预设新放置的细胞从 1 代开始计数，连续存活每代加 1，死亡归零；覆盖已有活细胞保留记录。移动突变成功后在目标格重新计数，移动失败保留原记录。暂停不增加记录，清空、随机填充或重新打开游戏会重置记录，切换速度和边界不会重置。

死亡／移动比例由同一条滑块控制，总和始终为 100%。左侧为死亡，右侧为移动；“向左加1”增加死亡比例 1 个百分点，“向右加1”增加移动比例 1 个百分点。滑块两端可设置为只死亡或只移动。只有保存后才应用修改；取消、关闭或按 `Esc` 会丢弃本次参数修改。弹窗打开时游戏快捷键不会改变场地或播放状态。

## 多模式操作

游戏顶部工具栏显示当前模式、笔刷和“切换模式”。主场地左键使用当前笔刷，右键擦除；Wireworld 的电子头和电子尾只在点击位置落笔，导线支持拖拽。Brian’s Brain 的亮色和暗色（将熄）笔刷均支持连续拖画。两种模式均不再提供独立的橡皮按钮，右键点击或拖拽即可擦除，且不会切换已选笔刷。形状编辑器使用相同的模式笔刷，已有的整体移动、点击增删和自动裁剪行为保留。

鼠标位于主场地或形状编辑器画布内时，滚轮向上切换前一种笔刷，向下切换后一种，首尾循环。Wireworld 按“导线 → 电子头 → 电子尾”排列，Brian’s Brain 按“亮 → 暗色（将熄）”排列；Conway 只有一种笔刷，无需切换。切换会同步更新笔刷按钮，不改变场地或历史。绘制、整体拖动、预设拖放和框选期间不响应滚轮切换；其他列表仍正常滚动，Ctrl／Meta 加滚轮的缩放不被拦截。

Wireworld 状态为：空白格保持空；导线在恰有一或两个电子头邻居时变为电子头；电子头变电子尾，电子尾变导线。Brian’s Brain 状态为：亮格变暗色（将熄），将熄格下一步变为空白，空白格恰有两个亮邻居时变亮；暗色格可以手动绘制，也能与亮格一起保存为自定义形状，重新打开和导入导出均保留状态。三个模式均使用八邻域、同步更新和当前选择的边界规则。突变只属于 Conway，在其他模式隐藏并停用。

Wireworld 与 Brian’s Brain 默认场景都可直接观察演化；Conway 默认放置居中的滑翔机。按 `R` 随机填充时，Conway 沿用 22% 活细胞密度，Wireworld 使用导线与少量电子头／尾，Brian’s Brain 使用 8% 亮格密度。

## 游戏规则

Conway 生命游戏每一代同时更新全部细胞：

- 活细胞有 2 或 3 个活邻居时存活，否则死亡。
- 死细胞恰好有 3 个活邻居时复活。
- 邻居包括上、下、左、右及四个对角线方向。

环绕边界将左右、上下连接起来；有限边界将场地外的位置视为死亡细胞。Wireworld 和 Brian’s Brain 使用相同的边界设置。

发布沿用现有 GitHub Actions 流程：同步版本元数据、补充 `docs/releases/vX.Y.Z.md`，提交源码后推送 `vX.Y.Z` 标签即触发桌面程序构建与 Release 上传。推送 `main` 会同步部署 GitHub Pages；开发分支不影响当前线上网页。
