康威生命游戏 v1.3.0 完善了细胞突变功能，新增「优先选择长期未改变的细胞」选项，并把死亡／移动比例改成一根滑块。下载下方附件即可使用。

## 本次更新

- **细胞突变新增「优先选择长时间未改变的细胞」**：在突变设置中勾选后，抽取时优先选择连续存活代数最多的格子；代数相同时随机挑选，同一次抽取不会重复选中同一个细胞。不勾选时仍按原来的完全随机方式抽取。默认不勾选。
- **连续存活代数按格记录**：新生、手动绘制和预设新放置的细胞从 1 开始计数，每存活一代加 1，死亡归零；用活细胞覆盖已有活细胞时保留原记录。移动突变成功后在目标格重新计数，移动失败（目标被占用或有限边界越界）保留原记录。暂停、切换速度或边界不会重置记录；清空、随机填充和重新打开游戏会重置。
- **死亡／移动比例改为统一滑块**：原来两个独立输入框改成一条 0～100 的滑块，左边是死亡、右边是移动，两侧实时显示百分比，两者之和始终为 100%。滑块两端可以设为只死亡或只移动。
- **新增微调按钮**：「向左加1」每次把死亡比例加 1 个百分点，「向右加1」每次把移动比例加 1 个百分点，到达两端后保持在 0% 或 100%。
- **设置改为保存后生效**：编辑过程中只修改弹窗内的草稿，点保存才应用；取消、关闭或按 `Esc` 会丢弃本次修改。弹窗打开期间游戏快捷键不会改动场地或切换播放状态。
- **兼容旧设置**：优先选项保存为原突变设置存储键中的新字段，旧数据缺少该字段时按不勾选处理；原先保存的死亡／移动比例会归一化后继续使用，不会丢失已有设置。

## 下载与安装

本次 Release 提供三个附件，适用于 Windows 10 / 11 x64：

- `Conway-Life-1.3.0-Windows-x64.exe` —— **Electron 免安装版**。双击即可运行，无需安装 Node.js、浏览器或其他依赖；程序已包含运行环境，可离线使用。免安装程序启动时会解压到临时目录，首次打开可能稍慢。
- `Conway-Life-1.3.0-Tauri-Windows-x64-setup.exe` —— **Tauri NSIS 安装版**，安装界面为简体中文，默认仅为当前用户安装。
- `Conway-Life-1.3.0-Tauri-Windows-x64.msi` —— **Tauri MSI 安装版**。

Tauri 的 NSIS 和 MSI 是同一种程序的两安装格式，**任选一种安装即可**，不需要都装。

`Conway-Life-1.3.0-SHA256SUMS.txt` 提供上述三个附件的 SHA-256 校验值。

## 使用说明

- 桌面版启动后默认最大化打开，直接显示游戏。按 `F11` 切换全屏，按 `Esc` 退出全屏。
- 主场地左键点击或拖拽绘制活细胞，右键擦除；`Space` 播放／暂停，`N` 单步，`R` 随机填充，`C` 清空。
- Tauri 版使用系统 WebView2；缺少 WebView2 的机器在安装时需要联网下载运行时，本项目不内置离线 WebView2 安装包。运行时安装完成后，游戏本身可以离线运行。Electron 免安装版不受此影响。
- 浏览器、Electron 和 Tauri 三种运行方式的自定义预设分别保存在各自的存储中，**不会自动互相迁移**。Electron 版预设保存在 `%APPDATA%\conway-life`，移动或替换 `.exe` 不会清除已有预设。
- 网页版仍可通过双击源码中的 `index.html` 运行，无需构建或启动服务器。

## 验证范围

本版本只做了静态与产物层面的核对：源码语法检查（`node --check` 三个脚本）、`git diff --check`、各版本文件号一致性核对、三个附件非空与大小核对、解包后内层程序为 x64 架构核对，以及三个附件的 SHA-256 计算与重新读取复核。

**本次没有运行游戏本体，没有执行安装测试，也没有做自动化冒烟测试**，因此不对运行与安装结果作任何已验证的表述。
