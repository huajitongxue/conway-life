## 本次新增

### 滚轮切换笔刷

在**主场地**或**形状编辑器**画布内滚动鼠标滚轮，就能切换当前模式的笔刷：

- **向上**滚切到前一种，**向下**滚切到后一种，**首尾循环**
- 电线世界按「导线 → 电子头 → 电子尾」排列，布赖恩大脑按「亮 → 暗色（将熄）」排列
- 康威只有一种笔刷，不需要切换
- 切换会同步更新控制区的笔刷按钮，**不改变场地，也不产生历史记录**

不会误触的情况：绘制中、整体拖动中、拖放预设中、框选进行中都不响应滚轮切换；预设库等列表照常滚动；`Ctrl`／`Cmd` 加滚轮的缩放不被拦截。

### 框选场地图案，直接存成新形状

以前想把场地上长出来的漂亮图案存下来，只能靠编辑器重画。现在点「形状管理」左侧的「**框选**」就能直接框：

- 点击后游戏**立即暂停演化和突变**，在主场地按住左键拖出矩形，**松开即保存**为当前模式的新自定义形状
- 单击可以提取单个格子；选框按格子对齐，支持任意方向拖动
- 拖出场地时终点限制在边缘，**即使当前是环绕边界也不会跨到另一侧**去选
- 保存时用当前最小可用编号命名为「预设N」，自动裁掉外围空白、保留内部间隔
- **康威只保存细胞位置；电线世界和布赖恩大脑保留每个方块的完整状态**
- 支持框选整张场地；**从倒放画面也能提取**，而且原场地、代数、历史位置和未来记录都不变

保存成功后自动退出框选；拖到空区域会提示重新选择；存储失败时不会加入临时预设，可以重新拖选重试。按右键、`Esc` 或再次点击「取消框选」都能退出；窗口失焦、切后台或指针被取消时放弃未完成的选框。**保存或取消后都保持暂停**，需要手动播放。

框选期间不能播放、前后导航历史或修改场地，但坐标和放大镜仍可用；打开形状管理、编辑器、设置等窗口前会先自动取消框选。

### 形状编辑器不再固定 80×50

- **默认仍是 80×50**，但编辑大形状时**会按图案各方向所需尺寸自动扩展**
- 图案整体拖动不会超出当前编辑区
- 重新新建空白形状时恢复默认尺寸

## 下载与安装

本次 Release 提供三种可执行文件，适用于 Windows 10 / 11 x64：

- `Conway-Life-2.0.0-beta3-Tauri-Windows-x64-portable.exe` —— **Tauri 免安装单文件**，约 9 MB，双击即用，不用安装。想快速试这个 Beta 就用它。依赖系统 WebView2。
- `Conway-Life-2.0.0-beta3-Windows-x64.exe` —— **Electron 免安装版**，约 96 MB，自带运行环境，不依赖系统 WebView2。
- `Conway-Life-2.0.0-beta3-Tauri-Windows-x64-setup.exe` —— **Tauri NSIS 安装版**。

`Conway-Life-2.0.0-beta3-SHA256SUMS.txt` 提供上述三个附件的 SHA-256 校验值。

**这一版同样没有 MSI**：MSI 使用的 WiX 要求版本号里的预发布标识必须是纯数字，`2.0.0-beta3` 会被拒绝，NSIS 没有这个限制。等 v2 转正式版后 MSI 会恢复。

**在线试玩**：<https://huajitongxue.github.io/conway-life/> 跟的是 `main` 分支，**仍是 v1.6.1，不含多模式功能**。要在线试 Beta，用浏览器打开本地 `web/index.html`。

## 验证范围

本版本只做了静态与产物层面的核对：源码语法检查（`node --check` 八个脚本）、`git diff --check`、脚本引用的页面元素逐一比对、各版本文件号一致性核对、依赖锁文件同步校验、三个可执行文件非空与大小核对、解包后内层程序为 x64 架构核对，以及三个可执行文件的 SHA-256 计算与重新读取复核。

逻辑层有十套本地检查脚本，共 **185 组**全部通过：Beta 改进 26、历史回放 34、历史开关 17、突变 9、预设导出导入 47、**框选与笔刷 18**、主题颜色 14、康威规则 5、Wireworld 规则 8、布赖恩大脑规则 7。

**这一版仍然没有实际运行过**——没有启动游戏本体，没有做视觉验证，没有执行安装测试，也没有做自动化冒烟测试。滚轮切换的触发范围、框选的拖动手感、边缘限制是否符合直觉，全部未经真人确认。**这正是它以 Beta 形式发布、并且不合并回主分支的原因。**

## 已知的限制

- **逻辑网格仍是 120×80**，Wireworld 里搭大一点的电路会嫌小
- 布赖恩大脑和电线世界**不启用细胞突变**，突变设置只属于康威模式
- 框选保存的形状走「自定义预设」的存储，与其他自定义形状共用同一个容量池
