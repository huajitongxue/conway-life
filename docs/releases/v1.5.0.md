康威生命游戏 v1.5.0 把自定义形状编辑器放大了一倍多，新增「整体拖动」，并修掉了 Tauri 桌面版「导出形状后找不到文件」的问题。下载下方附件即可使用。

## 本次更新

### 形状编辑器放大到 80×50

- 编辑器逻辑网格从 **40×30 扩大到 80×50**，显示区域同步改成 8:5，可以画下更大、更细的图案。
- 编辑器面板加宽到 920px，画布对应放大；原有格子尺寸保持不变，所以已有形状打开后看起来还是一样的格子，只是周围可用空间更大。

### 新增「整体拖动」

- 修改已有形状时，**从空白区域按住左键拖动，就能把整个图案挪到别处**，不用擦掉重画。
- 单击空白区域不会改变图案；在活细胞上拖动仍然是绘制／擦除，和原来一样。
- 图案会被限制在 80×50 编辑区域内，不会拖出边界产生越界格子。
- 新建空白形状时保持原来的绘制行为，空白区域不会误触发整体拖动。

### 修复：Tauri 桌面版导出形状后找不到文件

- 之前的版本里，Tauri 桌面版（免安装单文件与安装版）点「导出形状」后**文件其实导出成功了，但被静默存进系统的「下载」文件夹，既不弹对话框也没有任何提示**，很难找到。
- 现在桌面版会弹出 **Windows 原生「另存为」对话框**，可以自己选目录；保存后左下角提示里会带上完整路径。
- 网页版和 Electron 版的行为不变：网页版走浏览器下载栏，Electron 版弹保存对话框。

## 下载与安装

本次 Release 提供四种可执行文件，适用于 Windows 10 / 11 x64：

- `Conway-Life-1.5.0-Windows-x64.exe` —— **Electron 免安装版**。双击即可运行，无需安装 Node.js、浏览器或其他依赖；程序已包含运行环境，可离线使用。免安装程序启动时会解压到临时目录，首次打开可能稍慢。
- `Conway-Life-1.5.0-Tauri-Windows-x64-portable.exe` —— **Tauri 免安装单文件**，**只有 9.2 MB**。就是 Tauri 直接编译出来的可执行文件，自带全部依赖，双击即用，不用安装。体积比 Electron 版小十倍以上，代价是依赖系统 WebView2（见下）。想要体积最小、启动最快就选它。
- `Conway-Life-1.5.0-Tauri-Windows-x64-setup.exe` —— **Tauri NSIS 安装版**，安装界面为简体中文，默认仅为当前用户安装。
- `Conway-Life-1.5.0-Tauri-Windows-x64.msi` —— **Tauri MSI 安装版**。

Tauri 的 NSIS 和 MSI 是同一种程序的两安装格式，**任选一种安装即可**，不需要都装。Tauri 各版本都使用系统 WebView2：Windows 11 自带，Windows 10 通常也有；确实缺少时安装版会联网下载运行时，而**免安装单文件不会自动安装，缺 WebView2 时会启动失败**，这种情况请改用安装版。

`Conway-Life-1.5.0-SHA256SUMS.txt` 提供上述四个附件的 SHA-256 校验值。

## 预设导出与导入怎么用

- **导出形状**：点「导出形状」→ 勾选要备份的形状（点卡片即可，勾中会变灰）→ 点「导出所选」。桌面版会弹出「另存为」对话框；网页版则写成一个 JSON 文件下载到本机，文件名形如 `conway-life-presets-20261011.json`。文件只包含图案本身（名称、宽高和活细胞坐标），不包含场地、代数、速度和突变设置；卡片上临时做的左右／上下翻转也不会写进文件。
- **导入形状**：点「导入形状」→ 选择之前的 JSON 文件。文件里的图案会**追加**到预设库，不会覆盖或清空已有预设；无法识别的条目会被跳过，完成后提示实际导入和跳过的数量。文件不是有效 JSON、没有任何预设、超过 500 个预设或超过 2 MB 时都会给出提示，且不会改动已有数据。

## 使用说明

- 桌面版启动后默认最大化打开，直接显示游戏。按 `F11` 切换全屏，按 `Esc` 退出全屏。
- 主场地左键点击或拖拽绘制活细胞，右键擦除；`Space` 播放／暂停，`N` 单步，`R` 随机填充，`C` 清空。
- 浏览器、Electron 和 Tauri 三种运行方式的自定义预设分别保存在各自的存储中，**不会自动互相迁移**；换运行方式时可以用「导出形状」和「导入形状」手动搬运。Electron 版预设保存在 `%APPDATA%\conway-life`，移动或替换 `.exe` 不会清除已有预设。
- 网页版在线试玩：<https://huajitongxue.github.io/conway-life/>，也可以双击源码中的 `index.html` 运行，无需构建或启动服务器。

## 验证范围

本版本只做了静态与产物层面的核对：源码语法检查（`node --check` 三个脚本）、`git diff --check`、脚本引用的页面元素逐一比对、各版本文件号一致性核对、四个可执行文件非空与大小核对、解包后内层程序为 x64 架构核对，以及四个可执行文件的 SHA-256 计算与重新读取复核。逻辑层另有两套本地检查脚本（36 组预设场景 + 9 组演化／突变场景）全部通过。

**本次没有运行游戏本体，没有执行安装测试，也没有做自动化冒烟测试**，因此不对运行与安装结果作任何已验证的表述。另外，Electron 版的导出与导入、三个平台上的导入（选择文件）仍**尚未实测**。
