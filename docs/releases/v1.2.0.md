康威生命游戏 v1.2.0 重做了预设库与细胞突变，并新增 Windows 安装版。下载下方附件即可使用。

## 本次更新

- **预设库合并**：系统预设与自定义预设统一显示在右侧「预设库」中，每张卡片带缩略图，并支持左右翻转和上下翻转。翻转会同步更新缩略图、拖拽预览和最终放置方向，仅在当前页面会话内有效，刷新后恢复原始方向。
- **预设只支持拖拽放置**：不再点击卡片清空场地并居中加载。按住卡片拖到场地，松开位置作为图案中心，图案追加到现有细胞上，不清空场地。环绕边界下越界部分从另一侧出现，有限边界下越界部分裁掉。系统预设不可删除。
- **自定义预设使用最小空缺编号**：保存时命名为「预设1」「预设2」等，总是使用当前最小的可用编号；删除某个编号后再次保存会重新使用它。
- **细胞突变改为独立设置**：每秒抽取细胞数量、单个细胞突变概率以及死亡／移动比例都可单独调整。参数保存在本地，启用状态每次打开游戏时默认关闭。突变每秒独立触发，不会推进代数。
- **界面调整**：移除页面上方原有的占位区域，桌面端完整地图与控制面板同屏显示，预设列表独立滚动，窄屏改为上下布局。
- **新增 Tauri Windows 安装版**：在原有 Electron 免安装版之外，提供 Tauri 2 的安装程序。

## 下载与安装

本次 Release 提供三个附件，适用于 Windows 10 / 11 x64：

- `Conway-Life-1.2.0-Windows-x64.exe` —— **Electron 免安装版**。双击即可运行，无需安装 Node.js、浏览器或其他依赖；程序已包含运行环境，可离线使用。免安装程序启动时会解压到临时目录，首次打开可能稍慢。
- `Conway-Life-1.2.0-Tauri-Windows-x64-setup.exe` —— **Tauri NSIS 安装版**，安装界面为简体中文，默认仅为当前用户安装。
- `Conway-Life-1.2.0-Tauri-Windows-x64.msi` —— **Tauri MSI 安装版**。

Tauri 的 NSIS 和 MSI 是同一种程序的两安装格式，**任选一种安装即可**，不需要都装。

`Conway-Life-1.2.0-SHA256SUMS.txt` 提供上述三个附件的 SHA-256 校验值。

## 使用说明

- 桌面版启动后默认最大化打开，直接显示游戏，没有浏览器的标签页、地址栏和收藏夹栏。按 `F11` 切换全屏，按 `Esc` 退出全屏。
- 主场地左键点击或拖拽绘制活细胞，右键擦除；`Space` 播放／暂停，`N` 单步，`R` 随机填充，`C` 清空。
- Tauri 版使用系统 WebView2；缺少 WebView2 的机器在安装时需要联网下载运行时，本项目不内置离线 WebView2 安装包。运行时安装完成后，游戏本身可以离线运行。Electron 免安装版不受此影响。
- 浏览器、Electron 和 Tauri 三种运行方式的自定义预设分别保存在各自的存储中，**不会自动互相迁移**。Electron 版预设保存在 `%APPDATA%\conway-life`，移动或替换 `.exe` 不会清除已有预设。
- 网页版仍可通过双击源码中的 `index.html` 运行，无需构建或启动服务器。

## 验证范围

本版本只做了静态与产物层面的核对：源码语法检查（`node --check` 三个脚本）、`git diff --check`、各版本文件号一致性核对、三个附件非空与大小核对、解包后内层程序为 x64 架构核对，以及三个附件的 SHA-256 计算与重新读取复核。

**本次没有运行游戏本体，没有执行安装测试，也没有做自动化冒烟测试**，因此不对运行与安装结果作任何已验证的表述。
