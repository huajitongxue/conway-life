康威生命游戏现在有 Windows 桌面版了。下载下方附件 `Conway-Life-1.1.0-Windows-x64.exe`，双击即可运行，无需安装 Node.js 或其他依赖，支持离线游玩。

程序默认最大化打开，省去浏览器的标签页、地址栏和收藏夹栏。按 `F11` 切换全屏，按 `Esc` 退出全屏；细胞绘制、系统预设、自定义形状和速度控制均保留。

自定义预设保存在 `%APPDATA%\conway-life`，移动或更新程序不会清除预设。桌面版与浏览器版的存储相互独立，浏览器中已有的预设不会自动迁移。

本版本适用于 Windows 10 / 11 x64，免安装程序首次启动会解压到临时目录，请稍候。网页版仍可通过双击源码中的 `index.html` 运行，后续桌面程序也会统一通过 Release 附件发布。
