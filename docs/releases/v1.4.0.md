康威生命游戏 v1.4.0 补齐了预设库的管理能力：新增**形状管理**弹窗（可以修改已有形状、把任意形状复制一份），**导出形状改成勾选式**，**自定义形状可以改名**。下载下方附件即可使用。

## 本次更新

- **新增「形状管理」**：预设库标题旁的按钮换成「形状管理」，点开是一个弹窗，按预设库顺序列出全部形状（系统预设在前，自定义预设在后），最前面还有一个「＋ 新建空白形状」。新建和修改都从这里进，头部按钮数量没有变多。
- **可以修改已有形状**：在形状管理里点形状卡片就进入编辑器改它。编辑器会载入原来的图案，保存按钮变成「保存修改」，保存后**覆盖这个形状**，编号和名称保持不变；系统预设不能直接修改，点了会提示先「复制一份」。
- **新增「复制一份」**：形状管理里每张卡片都有「复制一份」，把该形状复制成一个新的自定义预设，名称自动取「原名 副本」「原名 副本2」等避免重名。系统预设也能这样复制成可自由修改的自定义预设。
- **导出形状改成勾选式**：不再一次性导出全部，点「导出形状」会进入选择模式。每张卡片左上角出现勾选框，点卡片本身就等于勾选或取消，勾中的卡片会**整块变成灰色**，一眼能看出选了哪些。上方换成「全选 / 导出所选 / 取消」三个按钮，「导出所选」上显示已勾选的数量。一个都没勾时会提示先勾选；按 `Esc` 或点「取消」可以退出且不导出。
- **系统预设也能勾选导出**：内置的滑翔机、脉冲星、高斯帕滑翔机枪同样可以勾上导出，再导入时就变成可以随意删除的自定义预设。
- **自定义形状支持改名**：卡片底部从只有一个「删除」变成「改名 / 删除」。点「改名」弹出输入框，名称最多 16 个字符，不能为空，也不能和另一个自定义预设重名；按 `Enter` 或点「保存名称」生效，按 `Esc` 取消。改名会立即写入本地存储。
- **导入保留原有名称**：导入的预设继续使用当前最小的可用编号，但**名称沿用文件里的名字**，只有文件里没有名字时才自动命名为“预设1”“预设2”。
- **细节**：选择模式期间暂停拖拽放置，避免点击和拖拽互相干扰；形状管理和改名弹窗打开时游戏快捷键不会改动场地或切换播放状态。

## 下载与安装

本次 Release 提供三个附件，适用于 Windows 10 / 11 x64：

- `Conway-Life-1.4.0-Windows-x64.exe` —— **Electron 免安装版**。双击即可运行，无需安装 Node.js、浏览器或其他依赖；程序已包含运行环境，可离线使用。免安装程序启动时会解压到临时目录，首次打开可能稍慢。
- `Conway-Life-1.4.0-Tauri-Windows-x64-setup.exe` —— **Tauri NSIS 安装版**，安装界面为简体中文，默认仅为当前用户安装。
- `Conway-Life-1.4.0-Tauri-Windows-x64.msi` —— **Tauri MSI 安装版**。

Tauri 的 NSIS 和 MSI 是同一种程序的两安装格式，**任选一种安装即可**，不需要都装。

`Conway-Life-1.4.0-SHA256SUMS.txt` 提供上述三个附件的 SHA-256 校验值。

## 预设导出与导入怎么用

- **导出形状**：点「导出形状」→ 勾选要备份的形状（点卡片即可，勾中会变灰）→ 点「导出所选」。选中的形状会写成一个 JSON 文件下载到本机，文件名形如 `conway-life-presets-20261014.json`。文件只包含图案本身（名称、宽高和活细胞坐标），不包含场地、代数、速度和突变设置；卡片上临时做的左右／上下翻转也不会写进文件。
- **导入形状**：点「导入形状」→ 选择之前的 JSON 文件。文件里的图案会**追加**到预设库，不会覆盖或清空已有预设；无法识别的条目会被跳过，完成后提示实际导入和跳过的数量。文件不是有效 JSON、没有任何预设、超过 500 个预设或超过 2 MB 时都会给出提示，且不会改动已有数据。

## 使用说明

- 桌面版启动后默认最大化打开，直接显示游戏。按 `F11` 切换全屏，按 `Esc` 退出全屏。
- 主场地左键点击或拖拽绘制活细胞，右键擦除；`Space` 播放／暂停，`N` 单步，`R` 随机填充，`C` 清空。
- Tauri 版使用系统 WebView2；缺少 WebView2 的机器在安装时需要联网下载运行时，本项目不内置离线 WebView2 安装包。运行时安装完成后，游戏本身可以离线运行。Electron 免安装版不受此影响。
- 浏览器、Electron 和 Tauri 三种运行方式的自定义预设分别保存在各自的存储中，**不会自动互相迁移**；换运行方式时可以用「导出形状」和「导入形状」手动搬运。Electron 版预设保存在 `%APPDATA%\conway-life`，移动或替换 `.exe` 不会清除已有预设。
- 网页版在线试玩：<https://huajitongxue.github.io/conway-life/>，也可以双击源码中的 `index.html` 运行，无需构建或启动服务器。
