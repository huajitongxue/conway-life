> **这是预发布版本（Beta 1），尚未验收。** 它把游戏从「一个康威生命游戏」改造成「方块规则模拟器」，发布在独立分支 `beta/multimode-v2` 上，没有合并回主分支。**最新的正式版仍是 [v1.6.1](https://github.com/huajitongxue/conway-life/releases/tag/v1.6.1)**，想要稳定版本请下载那一版。

v2.0.0 是一次结构性改动：**打开游戏后先进入模式选择页**，选一种规则系统再进场地。

## 本次新增

### 三种模式，共用一套界面

| 模式 | 每格状态 | 玩什么 |
| --- | --- | --- |
| 康威生命游戏 | 2 | 撒图案，看它演化 |
| 电线世界 Wireworld | 4 | 画导线，让电子跑起来 |
| 布赖恩大脑 Brian's Brain | 3 | 点几个点，看冲击波扩散 |

三种模式**都是二维 + 同步演化，画布始终是「场地」**——所以预设、形状编辑器、坐标、放大镜、主题颜色、历史回放、回放文件全都照常可用，不需要为某个模式换一套操作。

### 模式选择页

- 启动即进入选择页，三张卡片各有**实时循环播放的预览动画**
- 每张卡片写着模式名、英文名和一句话规则
- 键盘 `←`/`→` 切换焦点、`1`/`2`/`3` 直接选择、`Enter` 进入
- **不记住上次选择**——每次启动都从这里开始
- 场地顶部有「切换模式」按钮可以回到这里；切换会清空场地，**如果开着历史记录会先弹确认框**

### 电线世界 Wireworld

四种状态：空 / 导线 / 电子头 / 电子尾。

- 电子头 → 电子尾；电子尾 → 导线；导线遇到 **1 或 2 个**电子头相邻 → 变成电子头
- 有独立的笔刷：空、导线、电子头、电子尾，导线支持拖拽连续画
- 进入时自动放一个**时钟环**演示场景，立刻能看到电流在循环
- 自带这组系统预设（按「电路元件」理解）
- 默认速度 4 步/秒

### 布赖恩大脑 Brian's Brain

三种状态：亮 / 将熄 / 暗。

- 亮 → 将熄 → 暗；暗格周围**恰好 2 个「亮」** → 变亮
- 进入时撒 8% 随机初始密度，一进去就能看到冲击波扩散
- 只需要「亮」一种笔刷 + 橡皮（将熄是演化中间态，不手动画）
- 默认速度 15 步/秒

### 回放文件升级到格式 v2

- JSON 元数据里新增 `mode` 字段，二进制布局不变（每格仍是一个 UInt32）
- **旧版 v1 回放文件可以照常导入，自动按康威处理**
- 跨模式导入会被拒绝并提示——不同模式的格子含义不同，不能混用

### 预设与主题

- 预设带模式字段，列表**按当前模式过滤**；没有模式字段的旧预设按康威读取
- 三种模式各有自己的状态配色，跟着现有主题颜色一起变

## 下载与安装

本次 Release 提供三种可执行文件，适用于 Windows 10 / 11 x64：

- `Conway-Life-2.0.0-beta1-Tauri-Windows-x64-portable.exe` —— **Tauri 免安装单文件**，约 9 MB，双击即用，不用安装。想快速试这个 Beta 就用它。依赖系统 WebView2。
- `Conway-Life-2.0.0-beta1-Windows-x64.exe` —— **Electron 免安装版**，约 96 MB，自带运行环境，不依赖系统 WebView2。
- `Conway-Life-2.0.0-beta1-Tauri-Windows-x64-setup.exe` —— **Tauri NSIS 安装版**。

`Conway-Life-2.0.0-beta1-SHA256SUMS.txt` 提供上述三个附件的 SHA-256 校验值。

**这一版没有 MSI 安装包**：MSI 使用的 WiX 要求版本号里的预发布标识必须是纯数字，`2.0.0-beta1` 会被拒绝，NSIS 没有这个限制。等 v2 转正式版后 MSI 会恢复。

**在线试玩**：<https://huajitongxue.github.io/conway-life/> 跟的是 `main` 分支，**仍是 v1.6.1，不含多模式功能**。要在线试 Beta，用浏览器打开本地 `web/index.html`。

## 验证范围

本版本只做了静态与产物层面的核对：源码语法检查（`node --check` 八个脚本）、`git diff --check`、脚本引用的页面元素逐一比对、各版本文件号一致性核对、三个可执行文件非空与大小核对、解包后内层程序为 x64 架构核对，以及三个可执行文件的 SHA-256 计算与重新读取复核。

逻辑层有九套本地检查脚本，共 **160 组**全部通过：Beta 改进 24、历史回放 32、历史开关 17、突变 9、预设导出导入 44、主题颜色 14、**康威规则 5、Wireworld 规则 8、布赖恩大脑规则 7**。

**这一版完全没有实际运行过**——没有启动游戏本体，没有做视觉验证，没有执行安装测试，也没有做自动化冒烟测试。三种模式的手感、预览动画的性能、模式切换的体验，全部未经真人测试。**这正是它以 Beta 1 形式发布、并且不合并回主分支的原因。**

## 已知的限制

- **逻辑网格仍是 120×80**，Wireworld 里搭大一点的电路会嫌小（这次刻意不改，改尺寸会牵动历史、坐标、画布比例和回放格式）
- 布赖恩大脑和电线世界**不启用细胞突变**，突变设置只属于康威模式
- 开放问题：模式预览三个一起跑的性能、Wireworld 里电子头/电子尾是否该支持拖拽，都留给后续版本确认
