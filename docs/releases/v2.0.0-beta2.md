## 本次改动（相对 v2.0.0-beta1）

### 绘制工具更简单：去掉独立的橡皮按钮

初版在电线世界和布赖恩大脑里各放了一个「橡皮」笔刷，用起来要多点一次切换。现在改成**右键点击或拖拽直接擦除**，而且**不会切换当前选中的笔刷**——擦完可以接着画。

- **电线世界**：提供导线、电子头、电子尾三个笔刷。**导线支持拖拽连续画**；电子头和电子尾只在点击的位置落笔（避免一拖一条全是电子头）。
- **布赖恩大脑**：新增「**暗色（将熄）**」笔刷，和「亮」一样**支持点击与连续拖画**，右键擦除。

### 布赖恩大脑的「将熄」状态可以手动绘制与保存

- 三种状态现在叫**亮 / 暗色（将熄）/ 空白**：亮格变暗色，暗色格下一步变空白，空白格恰好有两个亮邻居时变亮。
- 暗色格可以**手动绘制**，也能和亮格一起**保存为自定义形状**；重新打开、导出导入都会保留状态。

### 放大镜加了准星

- 预览面板里用**黑白双描边的十字准星**标出鼠标的实际位置，在亮格和暗背景上都看得见，中心留出空隙不挡住细胞。
- **靠近场地边缘时，准星跟着真实的裁剪位置走**，不会固定在预览中央（初版在边缘处会误导位置）。
- 鼠标移出场地、窗口失焦或打开弹窗后，预览和准星一起清空，面板本身保留。

## 下载与安装

本次 Release 提供三种可执行文件，适用于 Windows 10 / 11 x64：

- `Conway-Life-2.0.0-beta2-Tauri-Windows-x64-portable.exe` —— **Tauri 免安装单文件**，约 9 MB，双击即用，不用安装。想快速试这个 Beta 就用它。依赖系统 WebView2。
- `Conway-Life-2.0.0-beta2-Windows-x64.exe` —— **Electron 免安装版**，约 96 MB，自带运行环境，不依赖系统 WebView2。
- `Conway-Life-2.0.0-beta2-Tauri-Windows-x64-setup.exe` —— **Tauri NSIS 安装版**。

`Conway-Life-2.0.0-beta2-SHA256SUMS.txt` 提供上述三个附件的 SHA-256 校验值。

**这一版同样没有 MSI**：MSI 使用的 WiX 要求版本号里的预发布标识必须是纯数字，`2.0.0-beta2` 会被拒绝，NSIS 没有这个限制。等 v2 转正式版后 MSI 会恢复。

**在线试玩**：<https://huajitongxue.github.io/conway-life/> 跟的是 `main` 分支，**仍是 v1.6.1，不含多模式功能**。要在线试 Beta，用浏览器打开本地 `web/index.html`。

## 验证范围

本版本只做了静态与产物层面的核对：源码语法检查（`node --check` 八个脚本）、`git diff --check`、脚本引用的页面元素逐一比对、各版本文件号一致性核对、依赖锁文件同步校验、三个可执行文件非空与大小核对、解包后内层程序为 x64 架构核对，以及三个可执行文件的 SHA-256 计算与重新读取复核。

逻辑层有九套本地检查脚本，共 **167 组**全部通过：Beta 改进 26、历史回放 34、历史开关 17、突变 9、预设导出导入 47、主题颜色 14、康威规则 5、Wireworld 规则 8、布赖恩大脑规则 7。

**这一版仍然没有实际运行过**——没有启动游戏本体，没有做视觉验证，没有执行安装测试，也没有做自动化冒烟测试。新增的右键擦除手感、暗色笔刷、放大镜准星的实际观感全部未经真人确认。**这正是它以 Beta 形式发布、并且不合并回主分支的原因。**

## 已知的限制

- **逻辑网格仍是 120×80**，Wireworld 里搭大一点的电路会嫌小
- 布赖恩大脑和电线世界**不启用细胞突变**，突变设置只属于康威模式
- 形状编辑器用的是各模式自己的笔刷，但 80×50 的画布对电路来说偏小
